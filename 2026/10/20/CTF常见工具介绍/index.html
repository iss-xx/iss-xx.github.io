输出解读技巧：

  • open：端口开放，有服务在监听
  • closed：端口关闭，但主机存活
  • filtered：端口被防火墙过滤
  • unfiltered：端口未被过滤，但状态未知
  • open|filtered：端口可能开放或被过滤
  • closed|filtered：端口可能关闭或被过滤

CTF 应用场景：

  • 发现目标主机开放的端口和服务
  • 识别服务版本，查找已知漏洞
  • 发现隐藏的服务（如 FTP、SSH、数据库等）

学习建议

第一阶段：基础工具掌握（1-2周）

  1. 熟练掌握 Burp Suite

    • 这是 Web CTF 的核心工具，必须精通
    • 学会使用 Proxy、Repeater、Intruder、Decoder
    • 练习拦截和修改请求

  2. 学会使用 Nmap

    • 掌握基础扫描和高级扫描
    • 学会解读扫描结果
    • 练习发现服务和版本

  3. 掌握目录扫描工具

    • 学会使用 Dirsearch 或 Gobuster
    • 了解常用字典路径
    • 练习发现隐藏路径

第二阶段：漏洞利用（2-3周）

  1. SQL 注入

    • 理解 SQL 注入原理
    • 熟练使用 SQLMap
    • 练习手动注入

  2. XSS 攻击

    • 理解 XSS 类型（反射型、存储型、DOM型）
    • 学会使用 HackBar 测试
    • 练习绕过过滤

  3. 文件上传漏洞

    • 理解文件上传漏洞原理
    • 学会上传 Web Shell
    • 练习绕过限制

  4. 命令注入

    • 理解命令注入原理
    • 学会使用 Netcat 获取反向 Shell
    • 练习提权技术

第三阶段：高级技术（3-4周）

  1. 密码破解

    • 学会使用 Hydra 进行在线破解
    • 学会使用 Hashcat 进行离线破解
    • 了解常用字典和规则

  2. 流量分析

    • 熟练使用 Wireshark
    • 学会使用过滤器
    • 练习提取隐藏信息

  3. 编码解码

    • 熟练使用 CyberChef
    • 了解常见编码类型
    • 练习多层编码解码

  4. Python 脚本编写

    • 学会使用 Requests 库
    • 学会使用 BeautifulSoup 解析 HTML
    • 编写自动化工具

第四阶段：实战练习（持续）

  1. CTF 平台练习

    • BUUCTF - 国内最好的 CTF 练习平台
    • Hack The Box - 国际知名渗透测试平台
    • TryHackMe - 适合初学者的学习平台
    • CTFHub - 国内 CTF 社区

  2. 本地靶场搭建

    • DVWA (Damn Vulnerable Web Application)
    • sqli-labs (SQL 注入实验室)
    • pikachu (综合漏洞靶场)
    • WebGoat (OWASP 官方靶场)

  3. 参加比赛

    • 关注国内外 CTF 比赛
    • 组队参加，学习团队协作
    • 赛后复盘，总结经验
